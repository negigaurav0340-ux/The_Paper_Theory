What is my password? How do I connect online publishing?

There is no preset password. In Vercel → your project → Settings → Environment Variables, set CATALOGUE_ADMIN_PASSWORD to a long unique password you choose. Also set CATALOGUE_REPO (your account/repository), CATALOGUE_BRANCH (usually main) and CATALOGUE_GITHUB_TOKEN (a private token with Contents read/write for this repository). Redeploy once. Never put the token in this page or in GitHub source.

After this setup, this page works on your live domain. Publish saves products, designs, packs and settings in ONE GitHub commit. Vercel's Git integration deploys that commit automatically. Without the connection you can edit and export, but cannot publish online.
