Order emails

How to switch on emails from thepapertheory.in@gmail.com
  1. Sign in to that Gmail account and turn on 2-Step Verification (Google Account → Security).
  2. Open myaccount.google.com/apppasswords, create an app password named “Website orders” and copy the 16 letters.
  3. In Vercel → your project → Settings → Environment Variables, add MAIL_APP_PASSWORD with those 16 letters. Never paste it into a chat, a file or this page.
  4. Redeploy once, then press “Send a test email”.

Optional variables: MAIL_USER (sending address, defaults to thepapertheory.in@gmail.com) and ORDER_ALERT_EMAIL (where alerts go, defaults to the same inbox).
